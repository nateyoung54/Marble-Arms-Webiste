# Marble Arms Website

This repository contains the foundational structure for the Marble Arms marketing website, built with [Astro](https://astro.build/).

## Setup

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server:

   ```bash
   npm run dev
   ```

3. Build for production:

   ```bash
   npm run build
   ```

## Project Structure

- `src/pages/` — Page templates for each primary site destination.
- `src/components/` — Shared layout and UI building blocks.
- `src/content/` — Placeholder content storage.
- `public/` — Static assets, including placeholder logo and photography.
